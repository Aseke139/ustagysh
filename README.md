# Тапсырыс ұстағыш 2.0 — как собрать и поставить

## Что нового в 2.0

- Новый дизайн по картинкам: батыр и такси в шапке, золотые кнопки ҚОСУ / ӨШІРУ, кнопки − / +, иконка с конём.
- Плавающая кнопка поверх inDrive: зелёная «ҚОСУЛЫ» / красная «ӨШІРУЛІ», рядом фильтр.
- Крестик ✕ и окно «Шығасыз ба?» в новом стиле.
- **Активация по ключу.** Без ключа приложение ничего не нажимает.
- Карточка «Батарея шектеуін алу», чтобы телефон не усыплял приложение.
- Кнопки − / +: если держать, цифра меняется быстро.
- Исправлена ошибка сборки: в репозитории было два файла CatcherService.

## 1. Сборка APK через GitHub

1. Откройте свой репозиторий `ustagysh` на github.com.
2. Удалите старые файлы, которых больше нет: `CatcherService (1).java`, `build.yml` (в корне),
   `OrnamentView.java`, `batyr_banner.xml`, `batyr_icon.xml`, `car_icon.xml`, и старый `.md` с кривым названием.
   Проще всего: создать репозиторий заново и загрузить всё содержимое этой папки.
3. **Add file → Upload files** → перетащите все файлы этой папки (вместе с папкой `.github`) → **Commit changes**.
4. Вкладка **Actions** → сборка «APK жинау» → дождаться зелёной галочки → **Artifacts** → `tapsyrys-ustagysh-apk`.

## 2. Установка

Ставится поверх старой версии (подпись та же). Настройки фильтра сохранятся.

## 3. Активация (ключи)

**Клиент:** открывает приложение → видит «Қосымша әлі іске қосылмаған» и свой **Телефон коды** (например `K7PM-2QXA`).
Жмёт зелёную кнопку **ІСКЕ ҚОСУ СҰРАУ** — открывается WhatsApp Асхату с готовым текстом и кодом.

**Асхат (вы):** на своём телефоне в приложении **держите картинку сверху (батыр и машина) 3 секунды** →
вводите PIN → вводите код клиента → **Кілт жасау** → кнопка **Жіберу** или **Көшіру**.

**Клиент:** вводит ключ `XXXX-XXXX` → **ІСКЕ ҚОСУ** → открывается главный экран.

- Ключ работает только на том телефоне, для которого сделан.
- Чтобы активировать свой телефон: держите картинку 3 сек → PIN → код уже подставлен → **Кілт жасау** → **Осында қосу**.
- После сброса телефона до заводских настроек код меняется — нужен новый ключ.

## 4. Первый запуск — тест

1. **РҰҚСАТ БЕРУ** → «Специальные возможности» → «Тапсырыс ұстағыш» → включить.
   Android 13+: если серое — Настройки → Приложения → Тапсырыс ұстағыш → ⋮ → «Разрешить ограниченные настройки».
2. **БАТАРЕЯ ШЕКТЕУІН АЛУ** → «Разрешить».
3. **Тест режимі** — включить. **ҚОСУ**. В inDrive при заказе внизу появится «СЫНАҚ · … — басар еді / Өткізілді».
4. Цифры верные — выключить **Тест режимі**.

## Плавающая кнопка

- Тап по кнопке — вкл/выкл. Тап по надписи с фильтром — открыть приложение.
- Тянуть — двигается. Бросить на ✕ внизу → «Шығасыз ба?» → ИӘ — кнопка убирается (вернуть: ҚОСУ в приложении).
